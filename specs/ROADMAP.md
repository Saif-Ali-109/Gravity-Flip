# Development Roadmap

## Phase 1 — Core prototype
- [x] Create repository and initial project scaffold.
- [x] Add product and technical specifications.
- [ ] Verify install, typecheck, and build.
- [ ] Implement robust four-direction gravity.
- [ ] Implement gravity-relative movement and collision tests.
- [ ] Create one complete prototype room.
- [ ] Verify touch and keyboard input.

## Phase 2 — Core game loop
- Data-driven level definitions.
- Collectible counter and completion state.
- Deterministic restart and next-level flow.
- 5 tutorial/challenge levels.

## Phase 3 — Art and UX
- Original character and environment art.
- Animation and visual effects.
- Audio, menus, pause, settings.
- Responsive landscape/portrait layouts.

## Phase 4 — Content
- Author and test 30 proposed levels.
- Difficulty and usability playtests.
- Accessibility and performance pass.

## Phase 5 — YouTube Playables integration
- Confirm developer program access and current SDK requirements.
- Integrate official SDK APIs from current documentation.
- Implement lifecycle, pause/resume, audio, saves, and scores as applicable.
- Run official test suite and platform-specific QA.

## Phase 6 — Submission
- Prepare metadata, icons, screenshots, age rating, and package.
- Review policies, rights, privacy, and asset licenses.
- Submit through the developer portal after access is granted.
- Resolve review feedback.

## Release gate
Do not describe the game as published, approved, SDK-certified, or cloud-saved until each corresponding action has actually happened.
